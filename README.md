# Discrete Probability Distributions

## 1. Project Title
Discrete Probability Distributions

## 2. About the Project
This is a web application developed for our lab assignment. It is based on discrete probability distributions and helps us understand how they work. We can enter different values and see the results of the calculations on the screen.

## 3. Modules Included
- Binomial Distribution
- Poisson Distribution
- Geometric Distribution

## 4. Features
- Simple and easy-to-use interface.
- Separate sections for each distribution.
- Users can enter values to perform calculations.
- Results along with graphs are displayed on the screen.
- Helps in understanding probability distributions through practical examples.

## 5. Technologies Used
- HTML for the structure of the application.
- CSS for the design and layout.
- JavaScript for calculations and functionality.

## 6. How to Run the Application
1. Download or clone the project from GitHub.
2. Open the project folder.
3. Open the HTML file(index(4).html) in a web browser.
4. Select a distribution and enter the required values to view the results.
